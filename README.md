# Users — справочник пользователей

Лабораторная работа №1 по дисциплине «Клиентские веб-приложения».
Вариант 5 — **Users**.

Одностраничное приложение на React для просмотра и редактирования списка пользователей.
Данные — моковые, в формате [dummyjson.com/users](https://dummyjson.com/docs/users).

## Технологии

React 19, TypeScript, Vite, Tailwind CSS 4, DaisyUI 5.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов и сборка в dist/
```

## Что умеет приложение

- список пользователей в виде карточек и сводная статистика;
- поиск, фильтры по полу и роли, сортировка;
- создание, редактирование (с валидацией формы) и удаление с подтверждением;
- сохранение изменений в `localStorage`, сброс к исходным данным;
- светлая и тёмная тема.

## Где смотреть код

| Папка / файл | Содержимое |
|---|---|
| `src/App.tsx` | корневой компонент: состояние и обработчики |
| `src/components/` | компоненты (`layout/`, `users/`, `ui/`) |
| `src/hooks/` | пользовательские хуки: `useUsers`, `useLocalStorage`, `useDebounce`, `useTheme`, `useToast` |
| `src/api/`, `src/data/` | слой доступа к данным и мок-данные |
| `src/utils/`, `src/types/` | вспомогательные функции и типы |
